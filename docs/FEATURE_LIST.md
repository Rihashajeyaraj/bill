- Premium card UI, spacing, shadows, hover motion
- 16px radius system
- Light/Dark theme toggle
- Responsive shell with mobile sidebar
- Sticky table headers and smooth table scrolling
- Loading skeleton support
- Toast notifications and confirmation modals
- Enhanced empty states

## SaaS Platform
- Global search (`Ctrl + K`)
- Notification center

- Session timeout
- Branch selector in topbar
- Activity logging

- Dashboard rebuilt with analytics and insight panel
- Company Setup extended (signature, FY, branches, bank details)

- Sales Invoice upgraded (due-date automation, partial payment, duplication, stock validation)
- Purchase Bill upgraded (supplier payable tracking, free qty, return reference)
- Reports export actions (PDF/CSV/Print)
- Backup module now functional (export/restore/log management)
