# Project Overview

## Product
Vyapar One is a premium billing and accounting frontend designed as a SaaS-ready application for SMEs and growing multi-branch businesses.

## Tech Stack
- React + Vite
- TailwindCSS
- Recharts (analytics)
- LocalStorage-backed services (mock persistence)
- Modular page architecture with reusable UI components and context providers

## SaaS Foundation Added
- Light/Dark theme system with enterprise palette
- Global command palette (`Ctrl + K`)
- Notification center + activity log stream
- Toast notifications and confirmation modal service
- Session timeout and role-aware route protection
- Branch selector support in shell

## Core Business Modules
- Dashboard
- Company Setup / Settings
- Parties
- Items
- Sales Invoice / Credit Note / Payment In
- Purchase Bill / Debit Note / Payment Out / Expense
- Reports
- Backup & Restore
