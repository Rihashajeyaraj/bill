# 1-Day Staff Training (Very Simple Steps)

Use this file to train new staff in one day.

Goal:
- By end of day, staff can do daily billing work without help.

Total Duration:
- 1 day (about 7 hours training + breaks)

## Training Rules

1. Use demo data first, real data later.
2. Do not skip sequence.
3. Trainer checks each step before moving ahead.

## Session Plan (Simple)

## Session 1 (60 min): Login + Basic Navigation

Staff must learn:
- How to login
- Which menu is used for what

Steps:
1. Open app and login.
2. Open each menu one by one:
   - Dashboard
   - Parties
   - Items
   - Invoices
   - Purchases
   - Credit Note
   - Debit Note
   - Payment In
   - Payment Out
   - Reports
3. Trainer asks: "Which page is for customer payment?"  
   Expected answer: `Payment In`.

Pass check:
- Staff can open correct page when trainer says page name.

## Session 2 (75 min): Parties + Items Entry

Staff must learn:
- How to create customer/supplier
- How to create item

Steps:
1. Go to `Parties`.
2. Create 2 Customers:
   - ABC Traders
   - Blue Star Retail
3. Create 2 Suppliers:
   - Metro Supplies
   - Prime Distributors
4. Go to `Items`.
5. Create 3 items:
   - Item A (Product)
   - Item B (Product)
   - Service X (Service)
6. Save and verify list.

Pass check:
- Staff can add, edit, and find a party/item in list.

## Session 3 (90 min): Sales Invoice + Payment In

Staff must learn:
- How to raise invoice
- How to record customer collection

Steps:
1. Go to `Invoices`.
2. Select customer `ABC Traders`.
3. Add 2 line items with qty and rate.
4. Save invoice.
5. Create second invoice for `Blue Star Retail`.
6. Go to `Payment In`.
7. Select customer `ABC Traders`.
8. Enter received amount.
9. Allocate amount to open invoice.
10. Save payment.

Pass check:
- Invoice created correctly.
- Payment allocation reduces pending balance.

## Session 4 (90 min): Purchase Bill + Payment Out + Expense

Staff must learn:
- How to record purchase and supplier payment
- How to enter expense

Steps:
1. Go to `Purchases`.
2. Select supplier `Metro Supplies`.
3. Add items and save purchase bill.
4. Go to `Payment Out`.
5. Select same supplier.
6. Enter paid amount.
7. Allocate to open bill.
8. Save payment out.
9. Go to `Expense`.
10. Add one expense (Office/Travel etc.) and save.

Pass check:
- Purchase bill visible in list.
- Payment out saved and allocated.
- Expense entry saved.

## Session 5 (60 min): Credit Note + Debit Note (Basic)

Staff must learn:
- Why adjustment pages exist
- Basic adjustment entry flow

Steps:
1. Go to `Credit Note`.
2. Select linked sales invoice.
3. Enter small adjustment and save (Draft/Issued).
4. Go to `Debit Note`.
5. Select linked purchase bill.
6. Enter small adjustment and save.

Pass check:
- Staff can link original document correctly.

## Session 6 (45 min): Reports + Daily Closing

Staff must learn:
- Day-end review process

Steps:
1. Open `Reports`.
2. Set date range to today.
3. Check:
   - Sales summary
   - Purchase summary
   - Receivables
   - Payables
4. Confirm all today entries appear.

Pass check:
- Staff can explain pending customer and supplier amount.

## Final Practice Test (30 min)

Trainer gives 5 tasks:
1. Add one new customer.
2. Add one new item.
3. Create one invoice.
4. Record payment in for that invoice.
5. Show report and confirm entry.

Pass criteria:
- 4 out of 5 tasks done without help.

## Daily Work SOP (after training)

Use this order every day:
1. Add/update Parties (if needed)
2. Add/update Items (if needed)
3. Create Sales Invoices
4. Record Payment In
5. Create Purchase Bills
6. Record Payment Out
7. Add Expenses
8. Check Reports before logout

## Common Mistakes (teach clearly)

1. Wrong customer selected in invoice.
2. Wrong tax/rate in item line.
3. Payment entered but not allocated.
4. Credit/Debit note without correct linked document.
5. Skipping report check at day end.

## Trainer Checklist

- Staff knows difference:
  - Payment In (customer money comes in)
  - Payment Out (supplier money goes out)
- Staff can create invoice from start to save.
- Staff can allocate payment correctly.
- Staff can read pending amount from report.

## Ready-to-Work Confirmation

Mark "Ready" only if staff can do below alone:
1. Create party
2. Create item
3. Create invoice
4. Record payment in
5. Record purchase and payment out
6. Enter expense
7. Read report

If all done: Staff is ready for live daily operations.
