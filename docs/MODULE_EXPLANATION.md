# Module Explanation

## Dashboard
- KPI cards (sales, purchases, profit, receivables, payables, low-stock signals)
- Monthly trend and profit-vs-expense charts
- Top-selling products and recent timeline
- Smart Insight Panel (growth, overdue, inventory risk)

## Company Setup
- Company profile + logo + signature
- Country/currency/tax model configuration
- Financial year and multi-branch setup
- Bank details and tax defaults

## Parties
- Customer/supplier directory
- Credit limit and outstanding tracking
- Statement/ledger integration
- Last transaction intelligence + WhatsApp action

## Items
- Product/service management
- SKU/barcode automation
- Low-stock threshold and inventory tracking
- Category filtering, margin visibility, CSV bulk import, stock movement history

## Sales & Purchase
- Tax-aware invoice and purchase flows
- Due date automation, partial payment capture, status badges
- Duplicate invoice, recurring/delivery-note flags
- Supplier payable tracking and free quantity capture in purchases

## Reports
- Multi-scope reports with charts and detailed tables
- Filter + sort + drilldown behavior
- PDF/CSV export and print actions

## Security & Admin
- Role-aware access guard for admin modules
- Session inactivity timeout
- Activity logs and notifications

## Backup & Utilities
- Full JSON backup export
- Restore from JSON file with confirmation
- Backup recency health tracking
