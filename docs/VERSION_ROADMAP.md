# Version Roadmap

## v1 (Current)
- Premium UI refresh and core SaaS shell
- Global command palette and notifications
- Dashboard analytics redesign
- Core module enhancements (company, parties, items, invoice, purchase)
- Backup and restore utility

## v2 (Next)
- Backend API integration with persistent database
- Real multi-user workspace and invitation workflow
- Advanced role/permission matrix enforcement per module/action
- Scheduled recurring invoices and automated reminders
- Full Excel import/export with templates

## v3 (Scale)
- Multi-tenant architecture with organization/workspace isolation
- Real-time collaboration (presence, live updates)
- AI-assisted forecasting and anomaly detection
- Approval workflows and audit export compliance packs
- Marketplace integrations (payment gateways, e-invoicing, GST portals)
